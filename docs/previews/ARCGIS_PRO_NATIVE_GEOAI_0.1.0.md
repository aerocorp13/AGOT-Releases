This is a genuine **Esri SDK-generated .esriAddInX**, built with .NET SDK 10 and ArcGIS Pro 3.7 targets. Its build checker inspected Config.daml and the compiled GeoTwins.GeoAI.ArcGISPro.dll assembly. It was **not** created by renaming a Python ZIP. A compiled archive does not prove it successfully loads or executes within licensed ArcGIS Pro.

## Evaluation installation
1. Prepare a compatible, properly licensed ArcGIS Pro 3.7 installation, Windows test environment and permitted test projects. Check Esri add-in security/vendor rules.
2. Download the named file from the published GitHub prerelease and independently verify its SHA-256.
3. Use your organization's approved ArcGIS Pro add-in installation procedure, then launch ArcGIS Pro.
4. Check the actual GeoTwins UI / ribbon or dockpane, local AGOT service connection, approved ArcPy toolbox hand-off and loss-of-server behavior.
5. Run reviewed GIS operations on test layers; verify result geometry, source rights, project preservation, exception handling and redacted diagnostic logs.
6. Document ArcGIS Pro build, Windows version, installed extension identity and observed results for the next release acceptance.
