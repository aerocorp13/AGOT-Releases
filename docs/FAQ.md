# Frequently asked questions

### What is AGOT?
An evolving Windows geospatial workstation by GeoTwins Africa. It integrates GIS and digital-twin foundations with governed GeoAI and a roadmap toward multiple comparable scenario worlds.

### What is the newest release?
**Desktop 1.0.2, Public Preview 3**, published 2 November 2026 UTC. The GitHub tag is `v1.0.1-preview.3`, which does not equal the installer version. [Open the release](https://github.com/aerocorp13/AGOT-Releases/releases/tag/v1.0.1-preview.3).

### Is AGOT free?
The currently published Windows installer is a **free public preview**. Do not assume future editions, private pilots, hosted services or commercial licensing terms are identical.

### Is this repository the application's source code?
No. This is the public installer/documentation distribution repository. The program's development source is held separately and is not included in automatically generated GitHub source ZIPs here.

### Does MIT mean the AGOT desktop binary is open-source?
No. The repository MIT license is for its public documentation and metadata, **not** the separately distributed proprietary application or private source. Installer terms and third-party notices take precedence for their respective components.

### Does the installer update itself?
Automatic desktop updates are **not established as enabled**. Visit [GitHub Releases](https://github.com/aerocorp13/AGOT-Releases/releases) for published builds. Website discovery of new releases is not automatic upgrade of installed copies.

### Is an LLM, segmentation checkpoint or cloud account bundled?
No blanket promise. Optional AI workflows may require a configured local provider or service; real ONNX segmentation requires a user-supplied compatible checkpoint. External imagery and map services can require internet and provider approval.

### Does every GIS, 3D, simulation and plugin operation work?
No. Features depend on engine, source permissions and data contract. Multi-world versioning, reviewed GeoAI jobs and GIS workflows are release-documented, but deep Cesium/Three integration and fully calibrated simulations have additional gates. See [Capabilities](CAPABILITY_MATRIX.md).

### Can AGOT replace ArcGIS Pro or QGIS in production?
That is **not** a claim of the current public preview. AGOT is developing its own evidence/World/GeoAI workflow rather than promising complete tool parity. Validate each professional task against accepted software and source data.

### What should I do with Windows SmartScreen warnings?
Check the original download URL, compare the GitHub-published SHA-256 and inspect the actual Authenticode status. Never disable security protections blindly or assume signing. See [Install](INSTALLATION.md).

### What is the primary use case?
Scenario Digital Twins for Climate-Resilient Infrastructure & Urban Planning in Africa, with source-governed baseline and alternative worlds. Fully validated scenario physics and scientific risk predictions are future work.

### How can I participate?
Provide a reproducible issue, suggest a practical GIS workflow or contact [admin@geotwins.org](mailto:admin@geotwins.org) about evaluation/pilots. Do not upload private geospatial or personal data to public issue reports.
